## Featured Projects

### War of Survival
**Multiplayer third-person action combat game** built with **Unity**, **C#**, and **Photon PUN**.

- Advanced melee combat with combos, blocking, dodging, crouching, and responsive locomotion
- Animation state machines designed for fluid combat and movement transitions
- Multiplayer synchronization built around low-latency gameplay goals

**Focus:** gameplay programming, combat systems, animation architecture, multiplayer synchronization

### NeuralSight
**AI accessibility prototype** designed to help users with upper-limb disabilities control a computer through **eye tracking**, **blink interaction**, and **voice commands**.

- Webcam-based gaze tracking with calibration and click interaction
- Speech-to-text command workflows for hands-free control
- AI-agent interaction layer for task execution

**Focus:** computer vision, accessibility, speech workflows, human-computer interaction

### AI-Based Warehouse Management System
**Warehouse simulation prototype** exploring AI-assisted scheduling and systems design.

- Producer-consumer workflows
- Semaphores and multithreading concepts
- Adaptive scheduling ideas for coordination and resource flow

**Focus:** systems thinking, concurrency, workflow simulation

### Cloud Resource Optimizer
**AI-based cloud resource allocation prototype** using workload analysis and informed search.

- Google Cluster dataset exploration and preprocessing
- Machine learning workflow for workload forecasting
- A* informed search for efficient allocation-state transitions

**Focus:** ML pipelines, optimization logic, resource scheduling

### Feast Delights
**Restaurant management system** centered on reliable relational database design.

- PostgreSQL and Supabase-backed data workflows
- Normalized schema for users, orders, inventory, and menu management
- Structured data modeling for consistency across operational modules

**Focus:** database design, backend data structure, operational workflows
